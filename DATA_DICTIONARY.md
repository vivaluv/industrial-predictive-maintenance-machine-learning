# Data Dictionary

## Dataset

**Dataset Name:** AI4I 2020 Predictive Maintenance Dataset

**Source:** UCI Machine Learning Repository

**Description**

The processed dataset contains operational sensor measurements and engineered features used to develop a machine learning model for predicting machine failure.

---

## Features

| Feature | Data Type | Description |
|----------|-----------|-------------|
| Air_temperature_K | Float | Air temperature measured in Kelvin (K). |
| Process_temperature_K | Float | Process temperature measured in Kelvin (K). |
| Rotational_speed_rpm | Integer | Rotational speed of the machine in revolutions per minute (RPM). |
| Torque_Nm | Float | Torque generated by the machine in Newton metres (Nm). |
| Tool_wear_min | Integer | Accumulated tool wear in minutes. |
| Type_M | Binary | Indicates a Medium-quality machine (1 = Yes, 0 = No). |
| Type_H | Binary | Indicates a High-quality machine (1 = Yes, 0 = No). |

Machine type uses one-hot encoding with **Low-quality machines as the reference category**:

- Low: `Type_M = 0`, `Type_H = 0`
- Medium: `Type_M = 1`, `Type_H = 0`
- High: `Type_M = 0`, `Type_H = 1`

---

## Target Variable

| Variable | Data Type | Description |
|----------|-----------|-------------|
| Machine failure | Binary | Target variable indicating machine failure (0 = No Failure, 1 = Failure). |

---

## Data Preparation

The following preprocessing steps are applied before model training:

- Removal of identifier columns (`UDI` and `Product ID`).
- One-hot encoding of the machine type variable.
- Removal of individual failure mechanism indicators (`TWF`, `HDF`, `PWF`, `OSF`, and `RNF`) to prevent target leakage.
- Selection of the final predictor variables.
- Stratified train-test split (80% training, 20% testing).
- SMOTE applied only to the training data through the modelling pipeline.
- Feature scaling applied within the machine learning pipeline where required.

---

## Machine Learning Task

### Problem Type

Binary Classification

### Objective

Predict whether a machine is likely to experience failure based on operational sensor measurements and machine characteristics.

---

## Final Model Features

The final tuned XGBoost model uses the following seven predictor variables:

1. `Air_temperature_K`
2. `Process_temperature_K`
3. `Rotational_speed_rpm`
4. `Torque_Nm`
5. `Tool_wear_min`
6. `Type_M`
7. `Type_H`

---

## Prediction Output

The deployed prediction system returns:

- Predicted Class (`0 = No Failure`, `1 = Failure`)
- Failure Probability
- Operational Decision Threshold (`0.9252`)
- Threshold-based Operational Decision (`0 = Normal Operation`, `1 = Maintenance Required`)
- Top local SHAP feature contributions
- Absolute SHAP contribution magnitude for each returned contributor

---

## Final Model

- **Algorithm:** Tuned XGBoost
- **Task:** Binary machine failure classification
- **Explainability:** SHAP (SHapley Additive exPlanations)
- **Operational Decision Threshold:** `0.9252`
- **Deployment:** FastAPI REST API with Streamlit Dashboard
